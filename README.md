**🚀 PulseNet – Social Media Platform**
PulseNet is a full-stack social media web application developed as a group project during the Sure Trust Internship.
The platform allows users to connect, share posts, like & comment, and chat with friends in real time using modern web technologies.

**🧑‍💻 Project Type**
Group Project
Internship Project – Sure Trust
Full Stack (MERN Stack)

**🛠️ Tech Stack**

Frontend
React.js
HTML5, CSS3
JavaScript (ES6+)

Backend
Node.js
Express.js

Database
MongoDB (Mongoose)

Authentication & Security
JWT (JSON Web Token)
bcrypt.js (Password Hashing)

Media Storage
Cloudinary (Post & profile image storage)

Real-Time Features
Socket.IO (WebSocket-based real-time chat)

**✨ Features**
🔐 Authentication
Secure user Sign Up & Login
Password encryption using bcrypt
Token-based authentication using JWT

##📝 Post Management
Create new posts with images
Delete own posts
Like & comment on posts
Images stored securely on Cloudinary

##💬 Real-Time Chat
One-to-one chat with friends
Real-time messaging using Socket.IO
Fast and responsive chat experience

##👥 Social Features
View posts from other users
Like and comment on posts
Interactive and user-friendly UI

 Frontend Setup
npm install

##🔑 Environment Variables

Create a .env file in the backend folder and add:
PORT=5000
MONGO_URL=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
CLOUDINARY_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
mail_id= your mail id
mail_app_password= your mail app password
BREVO_USER=your brevo user id
BREVO_PASS=brevo pass
api_key=brevo api key
